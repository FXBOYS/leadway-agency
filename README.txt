LEADWAY AGENCY WEBSITE - VERSION 1

FILES
index.html - website content
styles.css - design and mobile layout
script.js - menu and enquiry interaction
assets/ - brand mark and favicon

PREVIEW
Open index.html in a browser. An internet connection is needed for the optional Google Fonts; system fonts are used otherwise.

PUBLISH FREE WITH GITHUB PAGES
1. Create a GitHub account or sign in.
2. Create a new public repository named leadway-website.
3. Upload index.html, styles.css, script.js, and the assets folder to the repository root.
4. In Settings > Pages, choose Deploy from a branch, main, / (root), then Save.
5. Wait for GitHub to show the live URL.

IMPORTANT BEFORE LAUNCH
- Replace the disabled email placeholder with a verified company email.
- Add a verified business WhatsApp number if you want direct WhatsApp enquiries.
- Confirm service wording and regulatory scope.
- Verify the logo crop against the original official Leadway logo.
- The quote form generates a message for copying; it does not automatically transmit or save enquiries.
- Domain registration is optional and not included in free hosting.
